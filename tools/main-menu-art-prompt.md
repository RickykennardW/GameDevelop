# Starfall Bastion background generation

Final background generated with the built-in image generation tool (not the CLI). No reference artwork or stock download was used. The generated PNG is imported unchanged as `assets/ui/main_menu/starfall_bastion_background.png`.

## Final prompt

Use case: stylized-concept. Asset type: production 16:9 widescreen background painting for a real 2D tower-defense main menu called Starfall Bastion. Create one finished cinematic high-quality game-art landscape, landscape 16:9 composition. Ancient celestial civilization in deep space, mysterious distant COSMIC BASTION made of ivory astral stone and slender broken geometric spires with restrained gold inlays and violet/cyan energy seams, suspended over a dark nebula abyss. It must be an alien astronomical sanctuary, NOT a medieval castle, no battlements or gothic church, no spaceships, no humans. A huge partially shadowed violet-blue moon/planet is in the far RIGHT third, behind the distant bastion. The bastion sits low on the right third, atmospheric depth, beautifully painted intricate but restrained shapes. Wisps of lavender nebula form a faint luminous arc sweeping from left lower edge toward upper right, tiny distant stars, deep midnight blue and purple, restrained cosmic cyan and warm gold points. A few foreground floating ancient stone fragments at lower left corners create depth. Quiet, sacred, mysterious, premium indie fantasy-science-fiction art, painterly realism rather than cartoon. CRUCIAL UI NEGATIVE SPACE: the upper-center rectangle from x=20%-80% y=20%-42% is mostly clean dark navy space for a large title. The center/lower-middle rectangle x=34%-66% y=48%-82% is dark, low contrast, clear for two vertically stacked buttons. All bright detailed structures and moon remain to the sides so the central title and buttons are instantly readable. Keep essential subjects away from outer 6% edges. No text, letters, labels, logo, buttons, UI frames, watermark, illustration border or title embedded in this background. It is background artwork only for actual interactive GDevelop objects.

The separate title and button frames are project-native SVG artwork generated by `build-main-menu.py`. The title uses outlined Georgia letterforms, gradient metallic gold, and original celestial ornaments; no font file is distributed. START and EXIT GAME remain editable native text objects.
